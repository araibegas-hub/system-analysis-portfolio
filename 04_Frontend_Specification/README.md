Frontend Specification — Интернет-магазин мебели IKEA

Описание проекта

Учебный проект по подготовке технической спецификации требований к frontend-разработке интернет-магазина мебели на примере IKEA.

Цель работы — формализация требований к пользовательскому интерфейсу, описание функциональности каталога товаров и процесса добавления товаров в корзину.

Содержание документации

User Story — описание потребностей пользователя и ожидаемой функциональности.

Acceptance Criteria — критерии приёмки для проверки реализации требований.

Описание элементов интерфейса — наименования элементов, типы данных, форматы, обязательность, редактируемость и источники данных.

Use Case — сценарии взаимодействия пользователя с системой:

фильтрация каталога по категориям;

переход к подробному описанию товара;

добавление товара в корзину;

просмотр фотокарусели товара.

Альтернативные сценарии — обработка отсутствия товара, ошибок загрузки и технических сбоев.

Результат

Подготовлена спецификация, описывающая требования к пользовательскому интерфейсу, поведение системы при действиях пользователя и ожидаемые результаты выполнения основных сценариев.

Роль в проекте: системный анализ требований и подготовка технической документации для frontend-разработки.
